## 📝 Usage

1. Browse the scripts by topic in the subdirectories
2. Read the script header for dependencies and usage information
3. Make the script executable: `chmod +x script.sh`
4. Run the script: `./script.sh`

## 🔍 Finding Scripts

- Use `find . -name "*.sh" -type f` to list all scripts
- Use `grep -r "description" .` to search for specific functionality

## 📚 Notes

- Scripts marked with `✓ Syntax OK` have passed shellcheck validation
- Scripts with `✗ Syntax errors` may have style warnings or minor issues
- Some scripts require specific dependencies (listed in headers)
- Legacy scripts are kept for reference but may not be actively maintained
